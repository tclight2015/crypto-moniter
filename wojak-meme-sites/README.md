# Wojak Meme Sites

Shared React + Vite codebase for the five Wojak-themed meme coin landing pages
($LONELY, $CLUELESS, $JEALOUS, $SHOCKED, $SWEAR). One codebase, five static
deployments — each deployment only differs by which theme's config/images it
was built with. No backend, no login, no database.

## Structure

```
src/
  config/          one .config.js per theme (ticker, slogan, CA, socials, colors) + index.js theme resolver
  data/            {theme}.json image manifests, generated by the scripts below
  components/      Header, Hero, DrawSection, DrawButton, ResultCard, BuySection, Footer
  utils/           draw.js (random pick), share.js (clipboard + tweet intent)
  theme/           applyTheme.js — writes the active config's colors as CSS variables
public/images/     the 30 images per theme, served as static files
scripts/           asset ingestion (see below)
raw-uploads/       drop newly generated, picked, watermark-free art here before renaming
```

## Local dev

```bash
npm install
cp .env.example .env   # set VITE_THEME to lonely|clueless|jealous|shocked|swear
npm run dev
```

## Building one theme

Every deployment is a separate `vite build` with a different `VITE_THEME`:

```bash
VITE_THEME=swear npm run build
```

In Vercel/Netlify/Cloudflare Pages, create one project per theme pointed at
this same repo/folder, each with its own `VITE_THEME` env var set.

## Placeholder art vs. real art

The 30 images per theme are still being produced externally (AI-generated,
then hand-picked and watermark-cleaned). Until real PNGs land:

- `npm run generate:placeholders` regenerates 30 throwaway SVG placeholders
  per theme under `public/images/{theme}/` and their manifest under
  `src/data/{theme}.json`, so the draw/copy/share flow can be built and
  tested end to end right now.

When real art is ready (spec section 3):

1. Drop the picked files (any filename, PNG/JPG) into `raw-uploads/{theme}/`.
2. Run `npm run rename:assets -- lonely` (or with no theme arg to process
   every theme that has files staged).
3. This renames them sequentially to `{theme}-01..30`, copies them into
   `public/images/{theme}/`, and rewrites `src/data/{theme}.json` to match —
   overwriting the placeholder manifest. No code changes needed.

## Notes

- Clipboard image copy (`utils/share.js`) requires a real user click on HTTPS
  and browser support for writing that image's MIME type — test on real iOS
  Safari / Android Chrome before launch, not just desktop (spec 4.1). SVG
  placeholders may not be copyable to the clipboard in every browser; the
  final PNGs will be.
- Contract address, DEX buy link, and social links in each `*.config.js` are
  placeholders until those are finalized.
